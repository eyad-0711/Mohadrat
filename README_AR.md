# Mahadrati — Android Starter

مشروع بداية لتطبيق محاضرات مجاني يعمل على Android باستخدام Kotlin وJetpack Compose.

## الموجود حاليًا
- شاشة قائمة محاضرات تجريبية.
- خيارات تنزيل الصوت والفيديو والسلايدز بشكل منفصل.
- Worker بسيط لتنزيل ملفات مباشرة عبر HTTPS وحفظها في مساحة التطبيق الخاصة.
- ألوان كحلي وذهبي قابلة للتعديل.

## قبل التشغيل
1. افتح Android Studio وأنشئ/افتح مشروع Gradle من هذا المجلد.
2. استخدم JDK 17.
3. انتظر انتهاء Gradle Sync.
4. استبدل `https://YOUR_HOST/...` في `MainActivity.kt` بروابط مباشرة لملفات MP3/MP4/PDF تملك حق توزيعها.
5. شغّل التطبيق على جهاز Android أو محاكي.

## حدود هذه النسخة
هذه نسخة تأسيسية وليست تطبيقًا جاهزًا للنشر:
- زر التنزيل يرسل المهمة، لكن لا توجد شاشة تعرض التقدم أو قائمة الملفات المحمّلة بعد.
- لا يوجد مشغل داخل التطبيق في هذه النسخة بعد؛ التشغيل المحلي هو الخطوة التالية.
- لا يوجد فهرس Room مُفعّل أو حذف انتقائي من واجهة المستخدم بعد.
- روابط Firebase وFirestore وCloud Storage لم تُضف بعد؛ يلزم إنشاء مشروع Firebase وإعداد قواعد الوصول قبل استخدامها.
- تنزيل HTTP هنا لا يستأنف من منتصف الملف. أضف دعم HTTP Range للتنزيل القابل للاستكمال إذا كان السيرفر يدعمه.
- لا تستخدم روابط محمية أو ملفات لا تملك حق توزيعها.

## المعمارية المقترحة للنسخة الكاملة
- Firestore: metadata للمحاضرات (العنوان، ترتيبها، روابط المحتوى، الأحجام، إصدارات الملفات).
- Cloud Storage أو خدمة تخزين فيديو: ملفات الوسائط. اختَر التخزين وفق ميزانية النقل والتشغيل.
- Room: فهرس محلي للملفات المحمّلة وحالة التنزيل وآخر موضع تشغيل.
- Media3 ExoPlayer: تشغيل MP3/MP4 من الملفات المحلية، مع التشغيل عبر الإنترنت عند توفره.
- WorkManager أو Media3 DownloadService: تنزيلات خلفية موثوقة بحسب نوع الملفات.
- App-specific storage: تخزين دائم داخل `filesDir/lectures/`، والكاش فقط للملفات المؤقتة.
- شاشة إدارة التخزين: حجم الملفات، حذف الفيديو فقط، الاحتفاظ بالصوت والسلايدز، ومسح الملفات المؤقتة.

## إضافة Firebase لاحقًا
1. أنشئ مشروع Firebase وأضف تطبيق Android بمعرّف `com.example.mahadrati`.
2. نزّل `google-services.json` وضعه داخل مجلد `app/`.
3. أضف Google Services Gradle plugin وFirebase BoM وFirestore SDK.
4. أضف Firebase Storage فقط إذا اخترت استخدامه لتخزين الوسائط؛ قارن تكاليف تنزيل الفيديو قبل اعتماد الخدمة.
5. لا تفتح قواعد Firestore/Storage للعامة بلا قيود. للمحتوى المجاني يمكن السماح بالقراءة العامة فقط للملفات المنشورة، مع منع الكتابة العامة، أو استخدام روابط تنزيل مناسبة.

## تنبيه مهم
لو فيديوهات المحاضرات كبيرة، ارفع نسخًا مضغوطة مسبقًا. لا تضغط الفيديو على جهاز المستخدم عند كل تنزيل. اختبر H.264 كخيار توافق واسع، ثم قارن H.265 على الأجهزة المستهدفة. حجم الملف يعتمد على المدة ومعدل البت والمحتوى.
